钻具失效预测

钻柱在高狗腿度井段持续旋转，螺纹、接头等应力集中处可能因变幅载荷累积疲劳损伤。单凭断裂样本难以训练可靠寿命模型；因此结合 高频振动时序特征、S–N 材料曲线和 Miner 损伤约束，由工程师最终决定检查或起钻。

ENGINEERING BACKGROUND · WHY AI WORKS

在硬地层、高狗腿度和强烈井壁接触工况下，粘滑、横向涡动、旋转弯曲和屈曲会造成复杂的变幅载荷。SPE-145910-MS 报告了沿钻柱分布的动态测量与实际疲劳故障之间的关联。AI 的任务并非凭少量断裂记录“猜寿命”，而是把高频观测与可校准的疲劳物理规律结合，形成供工程师核实的风险证据。

01PROBLEM

钻具为何可能在几小时剧烈振动后迅速累积疲劳？

钻柱在井下同时受到轴向拉伸或局部受压、扭转、弯曲和冲击：钻头间歇停转再突然加速形成粘滑振动（Stick–Slip），伴随扭矩及瞬时转速剧烈变化；涡动（Whirl）使钻具偏心运动并反复撞击井壁；受压井段还可能出现屈曲变形。在坚硬地层和高狗腿度（DLS）井段，旋转中的弯曲杆体表面反复承受拉—压交替应力，接头螺纹根部和加厚过渡区的应力集中更值得关注。

现场为控制起下钻及更换成本，可能参考纯钻进时间或累计进尺制定检查计划。可同样进尺的两个井段，严重粘滑、涡动与大 DLS 导致的应力幅和循环数差别很大；短时高幅循环可能比长时间平稳旋转消耗更多疲劳寿命。仅按固定周期换钻具，既可能过度检修，也可能错过危险窗口。参见 SPE-145910-MS：Drill Pipe Dynamic Measurements Provide Valuable Insight Into Drill String Dysfunctions；1961 年井眼狗腿度与疲劳研究。

02INTERVENTION

为何不是纯 LSTM，而是“振动特征 + S–N / Miner”混合模型？

断钻具是极端稀缺事件，很多钻具会在失效前被预防性起钻，因此真实断裂时刻不可见，不能把“未断”当作“寿命还很长”。LSTM 或 1D-CNN 能从高频三轴加速度、扭振/扭矩序列中提取周期振动、粘滑波动、冲击及涡动特征，但仅凭网络很难在少量断裂样本上稳定学习应力—寿命规律。这并不意味着纯数据模型绝对不能用，而是它的外推、校准和少样本可靠性往往不足以独立支持高后果工程决策。

工程融合链条为：高频振动与动力学传感器 → 经几何和受力标定估计危险截面应力时程 → 雨流计数提取循环 → 由材料或接头 S–N 曲线确定寿命容量 → Miner 损伤累加。网络负责提取时序信息并预测损伤趋势/RUL，物理一致性损失约束结果符合疲劳累加趋势；加速度本身并不等于材料应力，应先完成传感器到载荷/应力的标定与模型映射。

为什么传统经验和纯 LSTM 各有盲区？
固定周期 / 进尺换具易理解、便于执行

同样钻进 100 m，低振动与强烈涡动的疲劳消耗可能完全不同；仅看时间难以反映载荷谱。

纯 LSTM 拟合断裂标签能捕捉时序，但依赖样本

断裂事件稀少，大量预防性更换是右删失，网络可能把“尚未断”错学为“足够安全”。

物理引导时序模型数据负责识别，机理负责约束

1D-CNN / LSTM 读振动与工况；标定后的应力谱经 S–N 与 Miner 给出损伤参考，再以损失函数惩罚明显违背疲劳规律的输出。

“给 AI 请一位物理老师”：真实断裂样本很少，不足以让模型单凭标签掌握所有疲劳模式。S–N 曲线像材料的“寿命课本”，Miner 累积像“疲劳记账本”；网络学习看不清的振动与工况变化，物理参考约束它别胡乱推断。这里只实现 physics-informed loss 的教学框架，不是从 PDE 出发求解完整钻柱动力学的严格 PINN。

研究依据：SPE-223731-MS（2025，钻杆全尺寸疲劳试验与累积损伤评估）；Raissi 等（2019），Physics-informed neural networks。

MINER'S RULE · LINEAR CUMULATIVE DAMAGE
D=∑ki=1niNiD ≥ 1 · 模型疲劳临界
ni某一交变应力水平下实际经历的循环次数，通过应力时程和循环计数估计
Ni同一应力幅值下，材料/接头由 S–N 曲线给出的临界循环容量
D各应力水平损伤比的累加，无量纲；达到模型临界需人工处置

工程解释：第 i 档交变应力在服役期间经历 ni 次，若单独施加该应力的疲劳寿命容量是 Ni 次，则该档贡献 ni/Ni。所有档位相加得 D。经典 Miner 在 D ≥ 1 时判为理想化疲劳失效临界；教学模拟据此停止，但真实钻具可能更早或更晚出现裂纹、洗穿或断裂，须按现场规程提前检查并由工程师决定起钻。

AI 如何服务现场：AI 将异常振动、井眼曲率、危险截面应力代理和累积损伤联合解释为“为何接近风险”，向工程师建议检查或起钻；模型不自动下发任何现场操作，人工审查及探伤结果会形成高价值标签。

04DIFFICULTY

高噪声、强漂移和稀缺断裂标签共同限制可靠性

信号噪声：破岩冲击、井壁碰撞、泥浆流动、局部共振与真实损伤相关的扭转/弯曲振动混叠。直接低通滤波可能损失关键高频信息；需结合转速与工况门控、时频特征、传感器频响标定及物理校核。环境漂移：井深、地层软硬交错、DLS、钻头磨损、钻具组合及腐蚀条件变化，会改变正常振动基线与 S–N 的有效容量，需要跨井段验证和不确定性估计。

标签稀缺：断裂案例极少，大量预防性更换属于右删失；不能把“没有断裂”误作长期安全。应关注漏报、误报、风险提前量、探伤一致性及按井/钻具分组后的泛化性能。线性 Miner 没有完整刻画载荷顺序效应、多轴疲劳及裂纹扩展，D = 1 只能作为选定模型的临界参考。

Human-in-the-loop：起钻有停工成本，继续钻进有钻具完整性和井下复杂事故风险。AI 负责提示理由和不确定性；工程师依据现场安全制度与真实检验信息作最终决定，不能因教学计算的 D 尚未到 1 就许可继续作业。

01PINN LOSS

为什么让网络“边看数据，边做疲劳物理作业”？

传统神经网络依赖大量“真实断裂时刻”样本，但现场更多是尚未断裂就被起钻的钻具。我们在损伤预测网络之外，加一条“材料物理老师”的监督路线：根据标定应力谱、雨流计数、S–N 曲线得到 Miner 损伤增量，训练时要求网络预测不能随意背离它。

COMPOSITE PHYSICS-INFORMED LOSS
L=Ldata+λ·Lphysics
经验教训：Ldata
MSE( RULpred, RULlabel )

仅对有可靠寿命标签的样本计算；其他样本要按右删失生存分析处理，不能直接当作已知寿命。

物理常识：Lphysics
( ΔDpred − ΔDMiner )² + μ[−ΔDpred]+²

一方面逼近 Miner 估计的损伤增量，另一方面禁止网络在持续服役中无依据地预测“负损伤”。

老师话语权：λ
λ ≥ 0

权重控制物理约束影响；需结合交叉验证与不确定性校准，不是越大越好。

这里的损伤物理项由 Miner 线性累积假设构造，并非直接求解钻柱应力场 PDE，也不是“能量守恒残差”。物理惩罚是软约束，不能保证所有工况预测都正确。

Python / PyTorch · 一个 Epoch 中的损失计算示意PHYSICS + DATA
# windows: 高频振动/扭矩窗口；d_prev: 历史损伤
# miner_delta: 已由应力反演、雨流计数、S–N 曲线算出
for windows, d_prev, miner_delta, rul_y, observed in loader:
    optimizer.zero_grad()
    damage_delta, rul_pred = model(windows)
    damage_pred = d_prev + damage_delta
    physics_target = d_prev + miner_delta

    # 只对真正有失效寿命标签的样本监督 RUL
    if observed.any():
        loss_data = ((rul_pred[observed] - rul_y[observed])**2).mean()
    else:
        loss_data = 0.0 * rul_pred.sum()

    loss_miner = ((damage_pred - physics_target)**2).mean()
    loss_mono = torch.relu(-damage_delta).square().mean()
    loss_physics = loss_miner + mu * loss_mono
    loss = loss_data + lam * loss_physics
    loss.backward()
    optimizer.step()

# 推理阶段只发出建议；最终起钻由工程师批准
recommendation = explain(damage_pred, rul_pred)

第一步，AI 看振动，猜这根钻具又损伤了多少；第二步，用材料试验的 S–N 曲线和 Miner 法则算一份“参考账本”；第三步，两份账对不上、或者 AI 预测损伤倒退，就给网络加罚；第四步，用少量可靠失效寿命标签纠正寿命预测。最后输出“为什么危险”的理由，交给工程师决定，而不是网络自己操作钻机。

02TRADE-OFF

为什么还需要工程师来“拍板”？

方案 A · 立即起钻检查/更换

多一次起下钻和检修，短期成本变高；但可以检查裂纹、减少高风险钻具继续服役的暴露。

主要考虑：完整性与风险控制
方案 B · 继续钻进最后 20 m（教学情境）

有机会完成眼前进尺，却继续增加疲劳损伤，且现场不能仅凭预测分数自行冒险作业。

主要考虑：工期与成本，同时面对不确定风险
AI 如何服务，而不是替人接管：它像“超级副驾”一样把异常、损伤和不确定性汇总给工程师；工程师结合钻具检验、井况和现行作业规程决定是否批准，并留下决策及结果。演示中的 20 m 仅用于展示工程权衡，不构成继续钻进建议。
