井眼清洁与岩屑运移优化

低侧岩屑床会使摩阻、扭矩与卡钻风险上升；盲目提高排量却可能使泵压和井底 ECD 越限。本案例演示如何用流动代理模型预测 + PSO 安全优化提出建议，再由司钻结合返砂等现场信息最终授权。

01 / PROBLEM DEFINITION · WHY AI WORKS

在高斜度井和水平井中，岩屑受重力滑向井眼下侧，流体剪切不足时形成岩屑床。提高排量可能提升清洁，但不能无限制加大泵压。 AI 的职责是在可行安全边界内快速比较参数组合，绝不能替代井控工程师和司钻。

01PROBLEM

岩屑为什么会在水平段堆积？

泥浆从钻柱内部进入钻头喷嘴，再沿钻杆与井壁之间的环空向地面返回。水平段重力分量将较大的岩屑颗粒拉向低侧，局部流速不足、泥浆屈服值不合适或钻杆偏心时容易形成静止岩屑床。积床可推高摩阻、扭矩、环空压耗，并增加缩径与卡钻风险。

把它想成一条平放的排水管：水在上侧流动，泥沙却可能留在管底。高斜度井同样如此；当钻杆偏心、岩屑粒径较大或局部剪切应力不足时，岩屑先滚动/滑移，再沉积成床。沉积后环空有效流通面积缩小，扭矩和起下钻阻力可能升高。问题并非只由一个“临界返速”决定。

经典定向井实验 Tomren 等，SPE-12123-PA（1986） 系统研究了井斜、流速、流变、钻杆旋转与偏心；SPE-20421-MS（1990） 区分低侧滚动/滑移与悬浮输运两种机制。它们共同支持一个现场判断：增排量有帮助，但“冲得越猛越好”并不成立。

为什么可能“冲漏”？泵排量增加通常会提高循环压耗，某些井段还可能推高 ECD，使井底压力接近或超过地层承压边界。只看地面立管泵压不足以判断漏失：还须独立计算环空压力剖面、ECD、破裂压力窗口及设备额定值。Busch 与 Johansen（2020） 的 CFD 研究还指出，钻杆侧向运动与偏心会改变岩屑床的剪切和携岩响应。

现场思路擅长什么容易忽略什么
经验固定排量操作直观、容易执行新井斜和新流变下的沉积/压耗差异
逐方案运行 CFD/DEM解析局部速度、岩屑迁移机理实时遍历大量候选的算力成本
CFD 代理 + 约束 PSO快速比较多组参数与安全裕度需要可信训练域、误差校准和人工授权
02INTERVENTION

让 CFD 做“教材”，让代理模型做“速查表”，让 PSO 替工程师试方案

Why Surrogate：真实 CFD/CFD–DEM 必须求解流场与颗粒相互作用，还要考虑非牛顿流变、岩屑粒径和钻杆偏心。单次计算成本可能明显高于普通回归推理；具体运行时间随网格、耦合与硬件而异，不能固定承诺“几十小时”或“0.01 秒”。可以先用实验数据 + 已校验的 CFD 样本训练代理模型，把排量 Q、转速 RPM、井斜、PV/YP、粒径等输入映射成床高、环空浓度和压力损失的预测，并在误差范围内快速评估候选方案。2025 年井眼偏心 CFD 研究显示这些条件确实会共同改变携岩效果。

Why PSO：候选的排量与转速互相牵制，且响应曲面未必凸。PSO 把每组参数看作一只“找食物的鸟”：每只记住自己发现的好方案，群体共享当前较优位置，反复修正搜索方向。它不保证全局最优，因此还要做离散网格复核、可行性检查及人工批准。

04DIFFICULTY

代理模型很快，但为什么不能直接自动控泵？

固液两相流涉及沉降、床面侵蚀、颗粒滚动和局部湍流；泥浆流变非线性，岩屑粒径分布也不断变化。代理模型若未见过某种井径或地层岩屑，可能高估携岩、低估压力风险。

Human-in-the-loop：司钻应核对岩屑筛返出、摩阻变化、钻具振动与井控窗口，可以要求“再循环 10 分钟”而非简单采纳机器推荐。页面参数、泵压红线和床厚清除率都是教学假设，绝不应用于现场自动控制。

02 / MACHINE ADVISES · DRILLER AUTHORIZES

五步理解：让机器快速试方案，让司钻决定执行

机器把昂贵的流固模拟压缩成一个快速预测器，再对多种排量和转速组合进行安全筛选；人工保留最后的执行权。

WHY NOT ONLINE CFD?

CFD 是“精细实验室”，不是现场快速试菜单

高分辨率模型能解释颗粒运动，但每改一次排量、转速都重新求解，计算量过大。代理模型是经 CFD/实验教过的速查表：快速预测而不代替实验校准。

WHY PARTICLE SWARM?

PSO 像一群鸟分头探路

粒子分头试不同 Q / RPM，结合各自最好经验与群体最好经验调整。先过硬安全门，再评估清洁成本；未找到安全解要诚实返回无解。

PSO 如何更新“找路方向”？PARTICLE VELOCITY UPDATE
vt+1 = ωvt + c1r1(pbest − xt) + c2r2(gbest − xt)

xt 表示本次排量/转速候选；pbest 是粒子自己试过的最好参数，gbest 是群体找到的最好可行参数。随机系数提供探索，惯性权重保持搜索趋势。更新后的候选仍须逐次接受泵压和 ECD 安全筛查。

核心伪代码 · PSO 先过安全门PYTHON · PSEUDOCODE
# 离线：用已验证的 CFD / 试验数据训练代理
surrogate.fit(cfd_cases, experiment_labels)

# 在线：多粒子搜索排量 Q 和转速 RPM
particles = init_swarm(flow=(18, 50), rpm=(40, 140))
for iteration in range(40):
    for p in particles:
        h, dp, pump, ecd = surrogate.predict(p.q, p.rpm, mud)
        feasible = (pump <= P_LIMIT and ecd_in_window(ecd))
        if feasible:
            score = w1 * norm(h) + w2 * norm(dp)
        else:
            score = float("inf")   # 越界直接淘汰
        update_pbest_gbest(p, score)
    update_velocity_position(particles)

proposal = best_feasible_or_none()
if proposal is None:
    ask_engineer_to_review() # 无安全解，不执行
else:
    request_driller_approval(proposal)  # 人类授权
