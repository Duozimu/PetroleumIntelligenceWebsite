【使用】
1. 若主站的 drilling 场景字典尚未包含 d10-npt，请先注册该场景。
2. 若主站技术字典尚未包含 nlp 或 ml，请注册这两个值。
3. 先解压 ZIP，拖拽 d10-npt 文件夹到平台的案例导入器（部分版本不直接接收 ZIP）。
4. 可单独双击 demo/index.html 在现代浏览器查看；所有 JS/CSS 均来自本地文件，禁止外部 CDN 依赖。
5. 页面顶部有 01 专业背景、02 案例流程、03 交互演示 三大 Tab。

【三大板块】
Tab 1：解释自由文本日报、NPT 归类、成本与稀有事件问题，包含时间分布 SVG 与分类交叉熵公式。
Tab 2：解释日报采集 → 实体识别 → 12/24h NPT 风险 → 人工决策 → 结果回流的五步流程；给出 Python 伪代码与生存风险公式。
Tab 3：自由文本一键解析（规则引擎教学模拟）、实体高亮、NPT 台账、风险曲线、工程师决策与日志。

【教学互动】
- 点击“一键 NLP 解析”，查看时间、井漏/等待钻具、处理措施与明确费用的高亮。
- 结构化表格可以修改“正常 / NPT / 待核实”归类；人工修正进入当前会话的审计记录。
- 通过井深、立压波动、设备状态控制未来 12/24 h 风险曲线。
- 选择“采纳预警，提前干预”后，绿色曲线代表更低危险强度的假设情景，并不代表已经防止事故。
- 选择“忽略预警”后，保持未干预情景并记录平台经理决定。
- 点击“重置演示情景”可恢复默认文本和参数。

【重要工程界限】
1. 页面采用正则表达式和领域词典作为 NER/NLP 的解释性代理；并未实际部署 spaCy、BERT 或训练好的领域模型。
2. 未来风险使用合成时间变风险强度函数，非工业 XGBoost/生存模型，不保证概率校准。
3. 平台经理的点击不会对现场钻机或泥浆系统发出任何控制指令。
4. NPT 必须与正常计划性非钻进作业、隐形损失时间区分。文字中没有的金额不能推断为真实费用。
5. 审计数据只保存在当前浏览器内存；刷新丢失，也不会自动训练模型。
6. 页面里的 12h/24h 数值、报表和示例成本都只是教学模拟，禁止用于生产调度决策。
7. 预测当前时间窗风险时，不能使用事故发生后才会知道的故障处理描述；要防止时间泄漏。
