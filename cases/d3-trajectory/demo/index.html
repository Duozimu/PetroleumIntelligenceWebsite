背景 / DRILLING TRAJECTORY

随钻测量（MWD）通常是离散测点，工具面控制的效应存在井下延迟与岩性扰动。工程师既要让钻头命中靶区，还要限制狗腿度、摩阻、工具负荷和滑动段比例。靶区命中不是唯一目标，平滑与安全同样重要。

01PROBLEM

轨迹偏离不是单次失误，而是持续累积的曲率误差

在长水平段与大斜度井，弯壳体马达的工具面方向与滑动段长共同决定可控曲率；但真实响应还取决于 BHA 刚度、钻头侧向切削力、井壁接触、层理倾角和岩石各向异性。不同层段的自然造斜或走向漂移（formation tendency / bit walk）会变化，不能仅用几何圆弧推算未来轨迹。[1] SPE-194727-MS

两类“滞后”必须区分：一是 MWD 测斜仪器到钻头具有空间间距，测到的是钻头后方的状态；二是测点间隔、井下信号上传与钻具响应形成时间或进尺上的反馈迟延。若工程师只根据最新测点的当前偏差执行单步大幅调整，可能在后续才发现修正过度。井眼一旦钻成，不能像车辆转弯那样撤销已经形成的曲率，纠偏代价会累积。[2] SPE-170861-PA

现场约束不是一个 DLS 数字。 大狗腿段可能使旋转钻柱承受更强的弯曲接触，并使扭矩与拖曳负荷变得敏感；实际摩阻受法向接触力、摩擦系数、井斜、张力、BHA 结构和井眼清洁等共同影响，不能认为扭矩与 DLS 始终呈固定二次关系。优化器应以批准的三维狗腿度限值、工具能力、摩阻与扭矩计算共同筛选候选。

02INTERVENTION

系统辨识提供“方向感”，MPC 提供“未来路线”

为什么先用系统辨识？ 若预测模型默认工具面响应增益恒定，遇到层理变化、BHA 受力和井壁摩阻变化就会发生模型失配。把已授权的工具面、滑动段长与后续 MWD 测点按井深对齐，可递推估计自然造斜偏置 β、工具响应增益 ĝ 与有效延迟；随后利用新观测更新下一窗口模型。物理机理 + 数据校正的工业思路可参见 [3] SPE-227896-MS。

为什么要用多步 MPC？ 井眼已经钻出的曲率不可撤销，狗腿度、工具极限及靶窗位置构成硬约束；单步贪心纠偏可能只改善最近一个测点，却在未来形成更大方向误差或急弯。MPC 比较未来 30 m 的控制序列，将位置误差、控制强度和控制变化率共同计入代价，再将通过约束的首段计划交由工程师审核。[4] 定向钻井 MPC 研究

PID 不是必然失效。 在模型近似稳定、信号及时、没有多种耦合约束时，PID 或增益调度控制仍有工程价值；但仅对当前误差反馈的单环 PID 不能天然表达未来多段靶窗、DLS 和滑动约束，这才是此场景使用 MPC 的主要理由。

强化学习（RL）亦可研究轨迹控制策略，但离线训练策略必须先经过历史回放、数字孪生、边界安全评估与现场审批。本互动演示采用简化辨识参数 + 单步滚动 MPC 代理，不宣称实际训练过强化学习模型。

状态空间方程 · 将地层扰动显式纳入预测 IDENTIFIED LINEARIZED MODEL
xk+1 = Axk + Buk + wk
离散线性化模型 · 以井段增量 Δs 为一个预测步长

在本教学二维投影中，状态 xk = (ek, ψk)T， 其中 e 为横向偏差（m），ψ 为相对设计方向角（°）； uk 表示滑动产生的有效转向曲率（°/m）， wk 表示未知的自然造斜扰动。 对小偏角线性化后，得到以下二维状态转移关系：

A= 1 Δs·π/180 0 1
状态转移矩阵 · 2 × 2
B= Δs2·π/360 Δs
控制响应矩阵 · 2 × 1
w≈ B·βgeo
地层自然造斜扰动

Δs 表示井段步长（m）。 上式使用 ψ 的角度单位（°），因此横向位移项需要乘以 π/180 进行角度到弧度的转换； B 的首项写成 Δs2·π/360，与原式 ½Δs2·π/180 完全等价。

工程适用性说明 这里的 βgeo 是按控制响应表示的地层自然方向漂移（°/m）， 并不等同于可直接测得的地层倾角。 真实工具面与曲率的关系通常非线性，需结合 BHA、岩性和执行记录持续辨识； 此处 A、B 仅为局部二维近似，不可直接用作现场三维井眼控制模型。

MPC：轨迹误差 + 工具面平顺性 + 狗腿度约束ROLLING-HORIZON OPTIMIZATION
J = ∑i=1N (xk+i − xref,k+i)T Q (xk+i − xref,k+i) + ∑i=0N−1 uk+iT R uk+i + ∑ Δuk+iT S Δuk+i

Q 惩罚偏离靶区和方向误差；R 惩罚过强的造斜控制；S 惩罚连续调整引起的激烈控制变化。另需约束 DLS ≤ 井段批准限值、工具面与滑动比例的可执行范围。对有效曲率控制进行局部线性化并使用二次约束/线性约束时，可形成二次规划（QP）；直接对工具面 cos(φ) 求解则通常是非线性问题。本网页采用离散候选搜索，模拟 MPC 的滚动规划，不宣称使用了 QP 求解器。

Q不要脱靶

偏差 e 和方向误差 ψ 的权重，数值越大表示越重视预测轨迹贴合目标。

R不要过度造斜

惩罚有效曲率控制量 u 的幅度，相当于克制频繁依靠大幅滑动纠偏。

S不要突然打方向

惩罚相邻井段 Δu 的变化，缓和工具面/曲率命令跳变及潜在井眼急弯。

约束：|uk+i+β| · 30 ≤ DLSlimit；umin ≤ uk+i ≤ umax；还需设备、扭矩/摩阻与井段限制。这里的 DLS 约束仅适用于局部二维等效曲率，非三维工程限值计算。

04DIFFICULTY

轨迹精度、狗腿约束和控制稳定性必须同时评价

为什么要有 Q、R 和 S？ 如果仅最小化末端偏差 e²，控制器可能用猛烈造斜“抄近路”。加入方向误差和控制增量项，才能显式抑制轨迹急弯与频繁工具面调整。这里的狗腿度是局部二维曲率代理；实际 DLS 应依据相邻三维井斜/方位用最小曲率法计算。

现场受 MWD 采样间隔、钻具滞后、扭振、地层非均匀性等因素影响，系统辨识可能偏移。单纯消除位置误差可能生成过大狗腿度；应将狗腿度、扭矩/摩阻、滑动比和工具额定限制纳入安全审批。评价指标至少包含靶窗命中率、横向误差、井斜/方位预测误差、DLS（°/30 m）、滑动效率、人工采纳率与审计覆盖率。

02ALGORITHM

可读的 MPC 核心循环：预测多步，但只执行获批的第一段

先辨识出局部 A、B、地层漂移 β；求解器在未来 N 步内平衡误差和控制变化，再把第一段候选提交工程师。新的 MWD 数据回来后重新辨识并求解，这叫滚动时域（Receding Horizon）。

Python / CVXPY MPC CORE可执行结构示例 · 不在网页运行
# 线性化二维局部模型；输入均来自可用测点的状态估计
# 本段演示 QP 结构：需要 Python 环境中的 numpy + cvxpy，网页不执行
import cvxpy as cp
import numpy as np

def propose_first_segment(x0, A, B, beta, x_ref, u_prev,
                          Q, R, S, u_max, dls_max, N=6):
    # 一步 = 5 m，N=6 对应未来 30 m；u、beta 单位 °/m
    U = cp.Variable(N)
    X = cp.Variable((2, N + 1))
    constraints = [X[:, 0] == x0]
    objective = 0
    for k in range(N):
        constraints += [
            X[:, k + 1] == A @ X[:, k] + B[:, 0] * (U[k] + beta),
            cp.abs(U[k]) <= u_max,                 # 工具可执行曲率
            30 * cp.abs(U[k] + beta) <= dls_max    # 教学二维 DLS 约束
        ]
        err = X[:, k + 1] - x_ref[k]
        du = U[k] - (u_prev if k == 0 else U[k - 1])
        objective += cp.quad_form(err, Q) + R * cp.square(U[k])
        objective += S * cp.square(du)
    problem = cp.Problem(cp.Minimize(objective), constraints)
    problem.solve(solver=cp.OSQP)
    if U.value is None:  # 不可行时必须回退到人工复核
        return None
    return float(U.value[0]), U.value.tolist()  # 首段建议 / 完整预测序列

# 控制权限不属于求解器：首段建议需工程师批准才可执行
# 下个有效 MWD 测点到来，再更新 beta、A、B 并重新求解
01 / N
滚动优化的核心：算出未来六段，只授权第一段。

上述程序求出未来 30 m 的 U[0]…U[5]，但只返回第一段 U[0] 作为待审批建议；新 MWD 测点到来后，用真实测量修正 β、A、B，再重新计算后续控制。如果当前约束没有可行解，程序返回 None 并转人工复核，而不是强行输出一条“最优指令”。

代码假定优化变量是线性化后的有效曲率，R、S 为标量非负权重，Q 为半正定矩阵，因此是典型凸 QP 的教学框架。将“工具面角度 φ、滑动段长 L”映射回现场动作时，需要单独处理非线性、控制延迟与可执行性约束。
