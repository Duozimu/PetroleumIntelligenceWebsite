井下复杂前兆预警

井漏与气侵的体积失衡、卡钻前扭矩异常往往和接单根、起下钻、泵速切换叠加。现场同一压力变化可能来自泵况或井筒事件，因此系统需先识别工况，再融合多变量时间窗口、机理残差和可解释证据；AI 提示风险，司钻根据现场井控程序做最终判断。

专业场景介绍

井下复杂预警不能靠单根曲线“亮红灯”。钻进与接单根的泵状态不同，立压、返出量和池体积本就会发生协同变化。先识别作业状态，再判断多通道关系是否偏离该状态的正常基线，才能在提前量与误报率之间建立可信权衡。

01PROBLEM

异常并非单一尖峰，而是多个微弱证据的组合

稳态循环中，返出流量 Qout 与入口流量 Qin 的差值，加上池体积变化，构成早期井漏/井涌筛查的重要证据；但泵启停、井筒储集效应、气体可压缩性和地面回流测量延迟都可能使其暂时失衡。立管压力 SPP 还受泵排量、泥浆流变与喷嘴压降影响；扭矩则随 WOB、RPM、井斜及摩阻变化。同样的“立压下降”在停泵与循环中的工程含义完全不同。 2024 年 SPE-221371-MS 明确采用不同作业阶段的识别和事件检测算法，以减少跨工况误判。文献：SPE-221371-MS

02INTERVENTION

混合检测：学“正常模式”，再解释“偏离在哪里”

以正常循环、接单根和起下钻等各类工况的时间窗口训练 AE / 1D-CNN-AE，可学习多传感器之间的正常耦合。实时窗口如果难以重构，说明其统计结构偏离正常样本，但高重构误差≠已经发生井涌。另一条证据链来自机理：比较出入口流量、池体积导数以及立压—泵况、扭矩—WOB/RPM 的条件残差；通过质量门控和方向一致性减少误报。SPE-218837-MS 报告了采用物理约束与数据驱动混合方案的实际井漏/井涌检测研究；SPE-231854-PA 则报道了基于 CNN-AE 的早期气侵检测研究。SPE-218837-MS SPE-231854-PA

04DIFFICULTY

真正难的是误报抑制与可信解释

正样本数量少，且真实井控事件与日常作业高度不平衡。含事件的相邻时间窗口若同时进入训练集和测试集，会发生时间泄漏；应按照井、井段或完整事件划分。风险评价不能只看 Accuracy，应考察事件级 Recall、提前量、每 24 小时误报次数（或每 100 次接单根误报数）、误报后复核成本和漏报代价；阈值需在独立现场数据上校准。断续泵、漂浮式钻机运动、传感器卡值、井下多相流均可能改变正常基线。

02WHY AI

Why｜为什么“线性趋势 + 死阈值”难以识别复杂前兆？

固定阈值隐含了“正常范围始终不变”的假设，而实际泵排量、钻压、转速、接单根与起下钻会不断改变正常值；线性回归即使使用多个通道，也较难表达跨时间的非线性耦合、阈值迟滞与多通道同向证据。AE 学习的是多变量正常窗口的联合形态，工况条件化降低把作业变化误报为事故的机会；流量守恒、压力与摩阻残差再提供物理可解释性。

规则阈值单通道越线 → 报警适用于清晰的硬安全限值，但不擅长复杂工况关联
AE + 机理联合偏离 → 核实证据先识别工况，再评估重构与守恒残差
人在回路分级解释 → 司钻研判确认、驳回和现场结果均留痕
03MODEL

How｜从“正常样本”学习重构基线，再叠加物理残差

1. 正常时序窗口的 AE 重构损失TRAIN ON NORMAL WINDOWS
LAE= 1N L C N∑n=1L∑t=1C∑c=1 (Xntc−X̂ntc)2

X 是标准化后的正常传感器窗口，X̂ 是 AE 重构；N 为窗口数、L 为窗口长度、C 为通道数。误差较高说明相对正常样本分布异常，并不能单独确诊事故。

2. 实时融合评分（教学设计）PHYSICS + DATA FUSION
St=100 · clip(0.20 eAE,t+0.80 rphys,t, 0, 1)
物理残差示例rflow = Qout − Qin − bflow(mode)
井况方向性井漏：rflow 向负、池体积下降；井涌：相反趋势

eAE,t、rphys,t 均需先经过正常工况分布归一化到 0–1，才能加权；0.20/0.80 仅是本教学仿真的示意权重。真实部署应由离线标注和误报代价校准权重与阈值，并对工况切换、坏点进行门控。

数学到底解决什么？第一式让网络尽可能“记住正常的多通道时序关系”；第二式把网络觉得“不寻常”的强度与流量、池体积等物理证据合并，输出用于排序核查的分数。高分不是事故概率，必须由司钻核实。

for window in normal_windows:

    x_hat = autoencoder(x)

# 在线推理阶段：以下函数表示算法接口，需另行实现
def warn(window, mode, autoencoder, baseline):
    if mode == 'pump_off':
        return '使用停泵专用基线并核实返出'
    x = standardize(window, baseline[mode])
    e_ae = normalize_ae(((x - autoencoder(x)) ** 2).mean())
    r_flow = flow_out(window) - flow_in(window)
    r_pit  = pit_volume_slope(window)
    r_phys = normalize_physics(r_flow, r_pit, window)
    score = 100 * clip(0.20 * e_ae + 0.80 * r_phys, 0, 1)
    return score, rank_evidence(window), '待司钻核实'
