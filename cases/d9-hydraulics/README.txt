导入：先确保主站的 drilling 环节注册 d9-hydraulics 场景，同时注册 ml 和 opt 技术标签。随后按主站导入器要求拖入解压后的文件夹，或拖入允许的 ZIP。所有依赖均为相对本地路径，支持隔离 iframe 静态运行。

三个 Tab：
01 专业背景：地面泵压预算、喷嘴压降和井底水功率的物理公式，工程数据和局限性。
02 案例流程：MLP 离线水力代理 + GA 硬约束搜索 + 工程师审批；附 Python 风格伪代码。
03 交互演示：SVG 双轴图、压力分配图、三喷嘴示意图、实时人工草案/执行状态与审计反馈。

关键交互：
1）拖动流量或密度滑块、选择喷嘴/PV，只预览候选；不会直接修改执行工况。
2）点击“采纳 AI 水力方案”，在满足教学压力/速度/功率/ECD 约束时，将推荐参数作为已批准模拟指令；排量渐变。
3）点击“执行人工设定”，若候选越限，界面转红并进入明确标记的“风险教学模拟”，绝不意味着现场可执行。
4）“手动降排量 2 L/s”仅修改草案，需要再审批。
5）下方日志逐条记录人工决策与参数，可作为后续离线模型校准的示意样本。

物理公式：
  At = Σπd²/4 （各喷嘴总面积，m²）
  ΔPbit = ρ Q² / (2 Cd² At²) （Pa，Q 用 m³/s）
  Pbit,kW = ΔPbit,MPa × Q,L/s
  Ppump = ΔPsystem + ΔPbit

教学模型：
• 虽然 Tab 2 介绍了 MLP 训练原理，但 Tab 3 实际使用的是简化机理代理与一个确定性小型 GA、有限网格可行性复核。没有训练、加载或部署真实 MLP 模型。
• 教学的 14 MPa 泵压红线、100 m/s 射流速度界限、850 kW 泵轴功率限额、1.10–1.43 g/cm³ ECD 窗口是虚构示意，不能用于实际井场。
• AI 推荐通常在默认泥浆条件下接近 32 L/s 与 3×12 mm；结果将随密度和 PV 改变，且非普适最优。
• 喷嘴组合属于下一趟钻具组合设计参数，井下不能实时远程改变喷嘴机械直径。
• 这里的井底水功率上升不能直接等同于机械钻速上升，也不能保证井底清洁改善。
• 所有数据为合成模拟，无真实泵控制、地面压力测量或井下传感器连接。
