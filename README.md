# 石油勘探开发智能化案例集

保留教师主站的作业链、检索、案例库与原有测井示范，内置十个 HW5 钻井案例。任何访问者首次打开都能看到十个钻井案例，不需要在浏览器导入 ZIP。

## 本地打开

双击根目录 index.html。进入“作业链 → 钻井”，即可按 D1 至 D10 的顺序查看全部十节，均带专业背景、案例流程和交互演示。主站原有测井案例一并保留，因此全站案例库共有十一个内置案例，其中钻井案例为十个。

## 上传 GitHub

1. 新建一个 GitHub 仓库，例如 petro-ai-atlas。
2. 进入仓库，选择 Add file → Upload files。
3. 把本文件夹里的内容全部上传。index.html 应直接位于仓库根目录，与 assets、cases 等文件夹同级。
4. 提交后，进入 Settings → Pages，选择 Deploy from a branch，分支选 main，目录选 / (root)，保存。
5. 等待部署完成，打开 Pages 中显示的网站地址。

若使用附带的 ZIP，请先解压，把解压后文件夹内部的内容上传。只上传 ZIP 文件本身不会发布网站。

## 内置钻井案例

1. 钻速预测与参数优化（drilling-rop-opt）
2. 井下复杂事故前兆预警（d2-alert）
3. 井眼轨迹智能控制（d3-trajectory）
4. 钻具失效预测（d4-fatigue）
5. 钻井液性能智能调控（d5-mud）
6. 井眼清洁与岩屑运移优化（d6-hole-cleaning）
7. 智能地质导向与储层追踪（d7-geosteering）
8. 邻井防碰与轨迹安全优化（d8-anticollision）
9. 钻井水力参数智能优化（d9-hydraulics）
10. 钻井非生产时间 NPT 智能分析（d10-npt）

## 文件用途

- index.html：网站入口。
- assets：教师主站代码、样式、ZIP 组件与十案例发布快照，必须整体保留。
- cases：十个案例的完整源文件副本，各自含 case.json、README.txt 和 demo 三文件。
- docs：案例接入与发布说明。
- .nojekyll：让 GitHub Pages 原样发布静态文件。
- tools：可选的案例快照更新工具，网站运行不依赖它。

## 发布后的保存行为

十个内置钻井案例来自网站文件，换电脑、换浏览器或清除浏览记录后仍可看到。访问者额外导入、隐藏或编辑的内容仍只属于其当前浏览器，不会自动修改 GitHub 仓库或其他访问者看到的内容。若要永久更新所有人看到的版本，需要修改网站源文件并重新上传。

## 修改案例内容

主站的十个内置钻井案例通过 assets/cases/drilling-packages.js 加载，该文件含案例清单与演示资源的静态快照。cases 目录方便检查和单独演示，修改它不会自动更新主站快照。

以后若修改了 cases 下的内容，可在安装 Node.js 的电脑上，进入本文件夹运行 `node tools/build-cases.cjs`，再把更新后的文件上传至 GitHub。首次发布无需安装软件或执行该命令，全部发布文件已经准备好。

工具按主站钻井场景的顺序生成快照，检查每个场景都有一个独立案例以及必要文件，D10 会排在 D9 后。以后增加场景时，应同时更新 assets/data.js 与 cases 文件夹。

本发布包保留当前已验证版本。发布后的数据、阈值与预测均为教学示例，不接入真实设备。
